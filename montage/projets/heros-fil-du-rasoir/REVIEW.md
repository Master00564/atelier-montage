# heros-fil-du-rasoir

Boucle de fond de 8 s, muette sur le site, pour le premier écran d'une maquette Click Street (demande d'Ali, 25/11/2026 : « animé, comme une vidéo, pas un zoom »). La musique n'est là que pour les portes du rendu ; le son est retiré à l'encodage pour le web. Seuils d'accroche, de son et de rythme relâchés dans `attendu` : ce n'est pas un film pour les réseaux mais un fond de page qui doit boucler sans couture (état à 8 s = état à 0 s).
